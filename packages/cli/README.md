# leglas

Compare design directions inside your own running app.

Leglas is a local, dev-only tool. It points at the dev server you are
already running and previews a set of design directions inside one chrome,
so alternates can be compared by flipping between them. It requires no
changes to the app it previews.

and does nothing. The first working release will land here.
