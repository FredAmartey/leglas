# Agent guidance

## Documentation assets

- Keep current assets tightly coupled to the Leglas code or documentation here.
- Put historical, shared or long-lived media in
  `https://github.com/FredAmartey/docs-assets`.
- Use the `projects/leglas/` namespace and a purpose directory such as
  `pull-requests/<number>-<slug>/`.
- Historical links must pin a docs-assets commit SHA, never `main`.
- Give every asset one canonical owner. Do not duplicate the same file in both
  repositories.
- Before moving or deleting an asset, search current documentation and linked
  historical pull requests for inbound references.
